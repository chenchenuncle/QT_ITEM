这是一个基于 Qt 框架的文件系统操作学习项目，用于演示和学习 Qt 中各种文件和目录操作相关的功能。

文件和目录的创建、读取、修改和删除
临时文件和目录的管理
文件系统监视

测试关于对I/O类，如：QFile和QFileInfo以及QDir，QTempoaryDir接口等等
